## 🔗 With Dynamic Tags Create Once. Update Never. ##
Static popups are limited. Every new product, every new sale, every new comment, you'd have to create a new notification manually. Notifal's Tag Generator changes that.

With dynamic tags, you create a notification once, and its content updates automatically based on real-time data. This is the engine behind every social proof and sales notification example above.

**🔄 How Tags Work**

Instead of writing static text like: ***"New Offer for You"*** You write: ***"New Offer for You, {user_name}"***. Now every visitor sees their own name. Sara sees ***"New Offer for You, Sara"***. Alex sees ***"New Offer for You, Alex"***.

With tags, you can pull in product names, prices, order details, cart totals, coupon codes, comments, usernames, and more, fully personalized, real-time notifications.

**🏷️ Three Powerful Tag Categories**

* **📝 WordPress Tags**: Post, Page, Comment, and User data.
* **🛒 WooCommerce Tags**: Order, Product, and Cart data including `{cart_total}`, `{cart_item_count}`, `{cart_coupons}`, and `{cart_checkout_url}`. Combine with **Cart Products** to rotate items from the live cart, related products, upsells, and cross-sells.
* **⚙️ Post Type Tag Generator [PRO]**: Have custom post types? Generate your own tags from any post type in your database. Complete flexibility.

== External services ==

This plugin connects to external services as follows:

* **Deactivation feedback**: When you submit the deactivation survey (Plugins → Deactivate), the plugin may send the following to notifal.com: site URL, admin email address, deactivation reason, and any optional details you provide (e.g. which plugin you switched to or additional feedback), plus plugin version, PHP version, and WordPress version. This feedback helps us improve the plugin and fix bugs. Data is only sent when you actively submit the survey.

* **Template library (pre-created on-page notifications)**: When you browse or import notification templates in the plugin, the plugin requests template listings, filters, and single template data from notifal.com. When you import a template, it requests a download URL and then downloads the template file and any template images from the provided URLs. The plugin sends only pagination, search, and filter choices (e.g. use case, layout); no personal data is sent. This is used only when you open the template library or click to import a template.

* **Support chat (Noti)**: In the plugin backend, the Notifal AI support widget is loaded from notifal.com. The plugin requests a short-lived signed embed token using authenticated admin AJAX and a signed Notifal plugin attestation. The widget may process technical usage data such as your site domain, browser/device details, and chat message content when you use the chat.

* **Notifal AI gateway**: When you use Setup Wizard analysis, account connection, or Generate with AI (OnPage, HTML Builder, Forms), the plugin communicates with `https://notifal.com/` from the server. It may send site identity (site UUID, home/site URL, environment), generation intent (goal, industry, layout, description, brand colors, optional existing HTML), active plugin display names, capability flags (for example WooCommerce).

* **Google reCAPTCHA / Cloudflare Turnstile (optional)**: If you enable captcha under Notifal → Settings → Forms, form pages may load scripts from Google or Cloudflare and the plugin may verify tokens with those providers' siteverify endpoints. Only used when captcha is configured and required for a form.

* **Mailchimp (optional)**: If you enable Mailchimp on a Form, submission email data is sent to Mailchimp's API using the API key you store on that Form. Only used when the integration is enabled.

* **Custom HTTPS webhooks (optional)**: If you configure a webhook URL on a Form, submission payloads are POSTed to that URL (SSRF-guarded). Only used when you set a webhook.

With the Cart Products content source, dynamic notifications can pull product content directly from the visitor's live cart, including related products, upsells, and cross-sells, and refresh automatically when the cart changes, helping you increase average order value with hyper-relevant offers at checkout time.

= Is Notifal compatible with my theme? =

Notifal is designed to work with any properly coded WordPress theme. Whether you're using a free theme, a premium theme, or a custom-built theme, Notifal will work smoothly.
